# 乡遇

**乡遇**是一款面向国内旅行与本地生活的原生 Android 应用，将万年历、实时天气和城市风物整合在同一个简洁界面中。应用可根据系统位置匹配所在地级市，也支持手动切换全国城市，集中查看当地小吃、民俗风貌、旅游景区、出行避坑、平价住宿和公共交通信息。

无论是计划一次异地旅行，还是重新认识自己生活的城市，乡遇都希望把“今天适合做什么、天气如何、哪里值得去、吃住行要注意什么”放在触手可及的一页里。用户还可以补充和修改地方资料，为条目添加个人笔记并通过记事本导入、导出和分享，让实用经验在亲友之间流转。

当前版本：`1.8.3`。已针对 Android 16 调整启动流程，并兼容雷电等定制模拟器系统栏实现：首次启动先显示完整首页，不再自动弹出位置权限；点击右上角城市后可手动选择城市或请求定位。启动窗口固定为不透明背景。顶部改用紧凑的安全间距，天气、黄历和景点轮播按首屏剩余高度排布，无需滑动即可完整查看景点照片及轮播指示。

## 已实现

- 系统定位与最近城市匹配，拒绝权限时自动使用上海作为默认城市
- 无需 API Key 的 Open-Meteo 实时天气，包含温度、高低温、湿度和风速
- 公历、农历、干支生肖、传统节日、二十四节气与每日宜忌
- 全国 337 个地级行政区离线目录与坐标，支持系统定位和省份/城市手动切换
- 北京、上海、成都、广州、西安、杭州以及河南 17 个地市使用经过区分的离线具体资料
- 其余 314 个地市按唯一地市代码生成城市专属内容与联网缓存，所有分类请求均绑定当前地市，不再复用同省城市列表
- 内置 373 条国家 5A 景区公开数据，按省份与地级市全名匹配；省直管条目按同省最近地市坐标归入
- 启动时校验 337 个唯一地市代码、名称、分类数量、条目归属和 373 条景区数据完整性
- 维基导游在线补充目的地景点和包含“注意、避免、预约、价格、交通、安全”等关键词的旅行建议
- 每个城市均有预约、消费和路程三类离线避坑提醒，在线内容缓存 7 天
- 避坑页补充小红书和抖音公开搜索线索，显示具体标题、摘要与来源，并提供平台及百度检索入口；公开笔记具有时效性和主观性，需与官方公告及现场信息交叉确认
- 小吃、风俗、景区、避坑、酒店和交通六分类；前五类可自主新增与修改，交通使用实时路线和车次数据
- “今日”独立展示天气与万年历，“发现”独立展示当地五类内容
- “发现”页按“小吃、风俗、景区、酒店、交通、避坑”显示六个固定分类菜单，仅下方推荐列表滚动
- “发现”页增加交通分类，以市内主要高铁/铁路枢纽为出发点规划前往景点的公共交通；省会城市可查询前往省内其他地市的次日直达列车、发到时间和历时
- 顶部品牌、副标题和城市位置固定显示并整体下移 10 像素，不随页面内容滚动
- 顶部品牌与位置进一步下移三个标题字符高度，首页黄历压缩排版，景点照片按首屏剩余高度自动缩放并优先完整展示
- 首页天气卡片进一步压缩，并在景点图片轮播指示点下方保留稳定空白；发现页五个分类菜单整体下移 10 像素
- 界面按实际可用宽高与屏幕比例自动适配，支持窄屏、长屏、横竖屏、分屏及模拟器动态修改分辨率
- 今日黄历增加节令、节日/节气、全年天数与周次，并扩充宜忌内容
- 今日页从中文维基百科及维基共享资源获取当地著名景点照片，支持自动和点按轮播
- 切换地市时首页图片按“城市代码 + 当前景点名单”重新获取；在线景点更新后自动刷新轮播，旧城市请求不会回填当前页面
- 小吃、民俗、景区和酒店详情按城市与具体条目获取实景图片，显示图片来源并缓存本次运行结果
- 小吃与风俗扩充至每城至少 5 条、精选城市最多 6 条，酒店扩充平价住宿类型与在线候选；详情优先补充百度百科、百度搜索或必应中国资料
- 每种小吃详情按城市与小吃名称补充 1 至 2 家公开搜索店铺候选，并提供百度地图和高德地图复核入口；候选不作商业排序，营业与地址须再次确认
- 景点列表合并在线与内置资料，点击景点可查看附近美食、住宿和交通汇聚点
- 有精确坐标的在线景点按 5 公里范围查询并显示距离；无坐标或断网时提供城市级参考
- 点击任意内容可添加私人笔记、编辑内容或调用系统分享；自建内容支持删除
- 笔记、自建内容和修改结果均保存在本机，升级或重启后继续保留；仅添加笔记不会用旧资料快照覆盖新版内置介绍
- “收藏”页支持导入和导出个人记事本；共享文件包含有笔记的条目与自建内容，导入时合并且不会清空本机其他数据
- 酒店模块提供市中心、交通枢纽、景区周边等离线住宿参考，并通过 OpenStreetMap 补充附近酒店；青旅、客栈、民宿、快捷酒店等平价住宿优先，明确三星及以上的酒店靠后补充
- 地方内容分类切换、收藏与本地持久化
- 网络或定位不可用时的降级展示

## 运行

1. 使用 Android Studio Ladybug 或更新版本打开本目录。
2. 安装 Android SDK 35，并使用 JDK 17。
3. 等待 Gradle 同步完成，然后运行到 Android 8.0 或更高版本的设备/模拟器。
4. 首次启动允许位置权限，以显示离当前位置最近的城市内容。

天气数据来自 Open-Meteo。地方内容随应用内置，因此断网时仍可浏览；离线天气会标记为“参考天气”。

## 构建

Windows：

```powershell
.\gradlew.bat assembleDebug
```

Linux 或 macOS：

```bash
./gradlew assembleDebug
```

调试 APK 会生成在 `app/build/outputs/apk/debug/app-debug.apk`。GitHub Actions 会在推送或拉取请求时自动执行同一构建，并上传 APK 构建产物。

## 数据来源

- 行政区划名称：`modood/Administrative-divisions-of-China`，基于国家统计局行政区划代码整理
- 城市坐标：`qwd/LocationList` 中国城市列表
- 目的地资料：中文维基导游 MediaWiki API，页面内容遵循 CC BY-SA 许可；应用内条目标注“维基导游”来源
- 附近景点：OpenStreetMap Overpass API，数据遵循 ODbL；应用内条目标注“OpenStreetMap”来源
- 国家 5A 景区：Lore Routes `china-5a-scenic-areas` 数据集，CC BY-SA 4.0；坐标来源包括中文维基百科、Wikidata 和 OpenStreetMap 贡献者
- 当地景点和条目图片：优先使用必应中国、百度图片搜索，Wikimedia Commons 仅作备用；应用内标注图片来源，版权以原页面为准
- 小吃店铺：百度、必应中国公开搜索结果及百度地图、高德地图检索入口；候选店铺不作商业排序
- 旅游避坑：小红书、抖音公开搜索线索及百度收录页面；内容具有时效性和主观性，不作为官方结论
- 天气：Open-Meteo API

在线资料仅作为行程参考。门票、开放时间、交通管制和消费价格可能变化，应用会提示用户在出发前通过目的地官方渠道复核。

## 项目结构

- `MainActivity.java`：界面绘制、导航、定位权限和交互
- `CalendarInfo.java`：农历、节日和节气计算
- `WeatherService.java`：实时天气请求与离线降级
- `LocalData.java`：精编城市资料，以及未精编城市的联网核实入口
- `CityContentService.java`：按地市代码获取并缓存城市级小吃和文化补充
- `ScenicAreaRepository.java`：加载并按地级市匹配 373 条国家 5A 景区数据
- `prefecture_cities.txt`：337 个地市的坐标与内容状态清单
- `UserContentStore.java`：用户新增、修改、笔记和删除数据的本地持久化
- `FoodShopService.java`：按城市与小吃获取店铺候选和地图复核入口
- `TravelTipService.java`：获取小红书、抖音公开避坑线索及搜索入口
