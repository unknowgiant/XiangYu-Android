# 乡遇

**乡遇**是一款面向国内旅行与本地生活的原生 Android 应用，将万年历、实时天气和城市风物整合在同一个简洁界面中。应用可根据系统位置匹配所在地级市，也支持手动切换全国城市，集中查看当地小吃、民俗风貌、旅游景区、出行避坑、平价住宿和公共交通信息。

无论是计划一次异地旅行，还是重新认识自己生活的城市，乡遇都希望把“今天适合做什么、天气如何、哪里值得去、吃住行要注意什么”放在触手可及的一页里。用户还可以补充和修改地方资料，为条目添加个人笔记并通过记事本导入、导出和分享，让实用经验在亲友之间流转。

当前版本：`1.9.3`。已针对 Android 16 调整启动流程，并兼容雷电等定制模拟器系统栏实现。全国 337 个地级市均内置具体的小吃、民俗和景区条目（离线可用，内容整理自公开百科资料）。首页和详情实景图通过必应图片搜索获取，并排除百度图片来源；小吃、平价住宿和景区周边优先读取高德开放平台官方 POI，显示具体店名、地址、距离及平台公开的评分和人均字段，美团、抖音和小红书保留为近期口碑核对入口。正式 APK 仅声明联网和粗略定位权限，禁止调试、应用数据备份及明文网络传输。首次启动会在任何在线请求前展示隐私保护说明，位置权限仅在用户主动操作后申请。

隐私政策：[查看完整内容](https://unknowgiant.github.io/XiangYu-Android/privacy.html)

## 已实现

- 系统定位与最近城市匹配，拒绝权限时自动使用上海作为默认城市
- 首次启动隐私保护说明、位置权限用途说明及收藏页常驻隐私政策入口
- 无需 API Key 的 Open-Meteo 实时天气，包含温度、高低温、湿度和风速
- 公历、农历、干支生肖、传统节日、二十四节气与每日宜忌
- 全国 337 个地级行政区离线目录与坐标，支持系统定位和省份/城市手动切换
- 全国城市均按统一完整结构展示，所有联网分类请求绑定当前地市代码和全名，不复用同省其他城市列表
- 百度百科城市词条的“著名景点”和百科联想条目共同生成具体景点、小吃和民俗列表，结果缓存 7 天
- 启动时校验 337 个唯一地市代码、名称、分类数量和条目归属
- 每个城市均有出租车与包车、低价团与购物、门票与二次收费、现场管理、餐饮住宿消费及远郊返程六类离线核查项
- 避坑页按风险主题读取小红书公开页面线索并提供平台直达入口；公开笔记只作为待核实线索，不直接认定问题仍存在
- 小吃、风俗、景区、避坑、酒店和交通六分类；前五类可自主新增与修改，交通使用实时路线和车次数据
- “今日”独立展示天气与万年历，“发现”独立展示当地五类内容
- “发现”页按“小吃、风俗、景区、酒店、交通、避坑”显示六个固定分类菜单，仅下方推荐列表滚动
- “发现”页增加交通分类，以市内主要高铁/铁路枢纽为出发点规划前往景点的公共交通；省会城市可查询前往省内其他地市的次日直达列车、发到时间和历时
- 顶部品牌、副标题和城市位置固定显示并整体下移 10 像素，不随页面内容滚动
- 顶部品牌与位置进一步下移三个标题字符高度，首页黄历压缩排版，景点照片按首屏剩余高度自动缩放并优先完整展示
- 首页天气卡片进一步压缩，并在景点图片轮播指示点下方保留稳定空白；发现页五个分类菜单整体下移 10 像素
- 界面按实际可用宽高与屏幕比例自动适配，支持窄屏、长屏、横竖屏、分屏及模拟器动态修改分辨率
- 今日黄历增加节令、节日/节气、全年天数与周次，并扩充宜忌内容
- 今日页以具体景点名称通过必应图片搜索获取 5-8 张当地实景图，检索词优先游客实拍与旅行摄影，并排除百度图片来源
- 切换地市时首页图片按“城市代码 + 当前景点名单”重新获取；在线景点更新后自动刷新轮播，旧城市请求不会回填当前页面
- 小吃、民俗、景区和酒店详情按城市与具体条目从必应图片搜索获取实景图，显示图片来源并缓存本次运行结果
- 小吃、风俗和景区联网列表均来自百度百科；点击条目后读取完整百科摘要，不再使用普通网页搜索结果兜底
- 每种小吃详情优先展示高德官方 POI 中的最多 5 家具体店铺，包含地址及可用的评分、人均字段；美团、抖音和小红书用于核对近期口碑
- 点击景点可查看约 5 公里内的高德餐饮、平价住宿、铁路/地铁/公交/停车等交通 POI 和直线距离
- 点击任意内容可添加私人笔记、编辑内容或调用系统分享；自建内容支持删除
- 笔记、自建内容和修改结果均保存在本机，升级或重启后继续保留；仅添加笔记不会用旧资料快照覆盖新版内置介绍
- “收藏”页支持导入和导出个人记事本；共享文件包含有笔记的条目与自建内容，导入时合并且不会清空本机其他数据
- 酒店模块通过高德官方 POI 优先检索青旅、客栈、民宿、宾馆和快捷酒店；明确三星及以上、高档类型或已知高端品牌的住宿不进入前五，美团和小红书用于核对近期住客体验
- 首页轮播通过图片内容指纹识别重复图片；具体景点不足时只用其他具体景点名补足，不使用“滨水公园、老城区”等通用条目凑数
- 景区在线补充扩展至亲子遛娃、红色学习、自然保护地、山峰瀑布、动物园和主题公园等小众类别；景区详情补充历史背景、核心看点、适合人群和行前信息
- 地方内容分类切换、收藏与本地持久化
- 网络或定位不可用时的降级展示

## 运行

1. 使用 Android Studio Ladybug 或更新版本打开本目录。
2. 安装 Android SDK 35，并使用 JDK 17。
3. 等待 Gradle 同步完成，然后运行到 Android 8.0 或更高版本的设备/模拟器。
4. 在未纳入 Git 的 `local.properties` 中增加 `AMAP_WEB_KEY=你的高德Web服务Key`，用于店铺和周边 POI；不配置时自动使用原有降级内容。
5. 首次启动允许位置权限，以显示离当前位置最近的城市内容。

天气数据来自 Open-Meteo。地方内容随应用内置，因此断网时仍可浏览；离线天气会标记为“参考天气”。

## 构建

Windows：

```powershell
.\gradlew.bat assembleRelease
```

Linux 或 macOS：

```bash
./gradlew assembleRelease
```

未签名的正式 APK 会生成在 `app/build/outputs/apk/release/app-release-unsigned.apk`，必须使用项目所有者保管的私钥签名后才能安装。GitHub Actions 会执行相同的 Release 构建和安全检查，但不会发布使用临时调试证书签名的安装包。

## 数据来源

地方内容按以下方式组织：

- 小吃、民俗、景区：全国每个地级市均内置 3 条具体条目，内容整理自公开百科资料，离线可用
- 高德开放平台 Web 服务：小吃店、住宿和景点周边餐饮/住宿/交通 POI 的名称、地址、距离及可用的评分和人均字段
- 美团：当地小吃店与平价住宿的公开检索入口，用于核对近期口碑
- 抖音：当地探店和住宿体验的公开搜索页及检索入口
- 小红书：当地探店、住宿体验，以及出租车、购物、门票收费、现场管理等旅行风险主题的公开页面及检索入口
- 必应图片搜索：当地景点、小吃、民俗和住宿的公开图片缩略图；应用排除百度图片来源，并使用具体地名和条目名检索

天气和铁路属于功能服务：天气使用 Open-Meteo，列车查询使用铁路 12306，路线规划跳转百度地图或高德地图。应用不登录平台账号、不调用美团、抖音或小红书私有接口，也不采集用户平台信息；必应仅用于公开实景图片搜索。

在线资料仅作为行程参考。门票、开放时间、交通管制和消费价格可能变化，应用会提示用户在出发前通过目的地官方渠道复核。

## 项目结构

- `MainActivity.java`：界面绘制、导航、定位权限和交互
- `CalendarInfo.java`：农历、节日和节气计算
- `WeatherService.java`：实时天气请求与离线降级
- `LocalData.java`：全国城市的统一离线结构与断网内容
- `CityContentData.java`：全国 337 个地级市的小吃/风俗/景点具体条目
- `BaikeService.java`：公开百科摘要、景点名称与联想条目
- `PhotoService.java`：通过必应图片搜索获取并去重当地实景图
- `AmapPoiService.java`：通过高德官方 Web 服务读取店铺和景点周边 POI
- `prefecture_cities.txt`：337 个地市的坐标与内容状态清单
- `UserContentStore.java`：用户新增、修改、笔记和删除数据的本地持久化
- `FoodShopService.java`：按城市与小吃读取高德店铺候选及公开平台核对入口
- `HotelRankService.java`：获取当前城市平价住宿候选并过滤高档住宿
- `TravelTipService.java`：获取小红书公开避坑线索、通用笔记及美团、小红书搜索入口
