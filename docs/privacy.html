乡遇隐私政策

更新及生效日期：2026年8月15日

乡遇重视您的隐私。本政策说明乡遇在提供万年历、天气、城市旅行信息、笔记和分享功能时如何处理信息。

一、我们处理的信息

粗略位置：仅在您主动点击定位并通过系统授权后读取，用于匹配当前地级市以及请求当地天气。您可以拒绝授权并手动选择城市，也可以在系统设置中随时撤回权限。

网络请求：应用会将城市名称、景点名称或城市坐标发送给天气、地图、百科、图片搜索及铁路等公开服务，以获取您主动查看的内容。天气服务在定位后可能接收到设备提供的近似经纬度。

个人笔记：您添加的收藏、笔记和自建内容仅保存在应用本机私有数据区。只有在您主动选择导出或分享时，相关内容才会交由系统文件选择器或系统分享面板处理。

二、权限说明

乡遇仅声明互联网访问和粗略位置两项权限，不申请短信、通讯录、电话、相机、麦克风、相册、存储、精确位置或安装其他应用的权限。

三、第三方服务

乡遇可能访问 Open-Meteo、高德开放平台、百度百科、必应图片搜索、铁路12306、美团、抖音和小红书的公开服务或公开检索页面。应用不登录您的第三方账号，不读取第三方账号资料，也不接入广告、支付或用户行为统计 SDK。第三方服务会依据其各自的隐私政策处理网络连接所必需的信息。

四、保存、共享和保护

乡遇不设用户账号，不运营自有用户数据库，不出售个人信息。应用已关闭系统云备份与设备迁移，网络请求使用 HTTPS。导出的记事本文件及通过系统分享的内容由您自行决定保存位置和接收对象。

五、您的权利

您可以拒绝或撤回位置权限、手动选择城市、删除笔记和自建内容，或通过卸载应用清除全部本机数据。撤回位置权限不会影响万年历和手动选城等基础功能。

六、未成年人保护

乡遇面向一般旅行与生活信息场景，不要求未成年人提交姓名、联系方式或身份信息。未成年人应在监护人指导下使用分享及外部网页功能。

七、联系我们

如对本政策或个人信息保护有疑问，请通过项目的 GitHub Issues 联系开发者。
